# PathOS: Interface Layer

This is the Next.js frontend for **PathOS**, featuring a cyberpunk/high-tech aesthetic.

## ⚡ Key Features

- **Cyberpunk UI**: Dark mode by default, grid-based layouts, and spotlight animations.
- **Protocol Visualization**: Granular, week-by-week roadmap rendering with interactive progress tracking.
- **Custom Components**:
  - `Preloader`: System boot sequence simulation.
  - `CustomCursor`: Reactive cursor with crosshairs and color-shifting states (Amber/Emerald).
  - `BaryonLoader`: Minimalist geometric pulsing loaders.
  - `DecryptedText`: Character-scrambling animation for headings.

## 🛠️ Technology

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Motion**: Framer Motion
- **Icons**: Lucide React

## 🚀 Development

```bash
npm install
npm run dev
```

Ensure the backend is running on `http://localhost:8002` for full functionality.
